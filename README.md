# LinkVault SEO Database Landing Page

A GitHub Pages-ready static website for selling a digital SEO link-building prospect database.

## Files
- `index.html` — page structure and content
- `style.css` — responsive design and styling

## Before launch
1. Replace the brand name `LinkVault`.
2. Replace the sample data with your real sample.
3. Add your real Terms, Privacy and Refund Policy pages.
4. Connect the three purchase buttons to your payment provider (Razorpay/Cashfree/PayU/etc.).
5. Set up secure post-payment delivery. **Do not put your complete paid Excel databases inside this public GitHub repository.**
6. Add Facebook/Meta Pixel and conversion tracking after your checkout flow is working.
7. Test checkout and download on mobile and desktop.

## GitHub Pages
Upload `index.html` and `style.css` to a GitHub repository, then enable:
Settings → Pages → Deploy from branch → main → /(root).

## Payment
The current page intentionally contains a placeholder payment action. A real payment gateway should be connected using its official checkout/integration flow. The public frontend should not contain secret API keys.
